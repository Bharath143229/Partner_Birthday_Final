PARTNER BIRTHDAY V1 — UPDATED

Added without changing the original overall V1 screen-based interface:
- 10-photo one-at-a-time memory slideshow
- 10 quotes, one per photo
- Google Apps Script wish saving hook
- Download Greeting button
- Mobile/public-hosting ready relative paths

IMPORTANT:
1. Add photo01.jpg through photo10.jpg to the photos folder. The current ZIP contains only photo01.jpg.
2. In script.js, replace PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE with your Google Apps Script Web App URL ending in /exec.
3. Run locally with: python -m http.server 8000
4. Open http://localhost:8000
5. For public mobile access, upload the Partner_birthday folder to GitHub Pages.
